# PulseZ · 偏心电波

一个运行在你手机本地、能接回旧聊天记忆、自带模型接口的 AI 情感陪伴客户端——不是回答，是同频的温暖回应，且不渲染孤独、不诱导依赖。填一个 OpenAI 兼容的地址和密钥，自己搭一个人设，然后一直聊下去。聊天记录保存在手机上，生成回复时相关内容会发送给你选择的服务商。

1. 这是一个实验性的 AI 聊天客户端，**不提供模型服务**。
2. 你需要自己准备 OpenAI 兼容的接口和密钥，**费用由你自己承担**（具体花费以你的服务商账单为准）。
3. 当前社区开源版**无需账号即可自带密钥使用**；聊天记录保存在手机上，生成回复或使用「找旧事」时相关内容会发给你选择的服务商。**你发送的图片、文件和语音输入录音也会发给相应服务商处理**；自动朗读使用手机自带的声音，**文字可能被手机语音引擎厂商收到**（取决于手机与音色）。
4. 软件按现状提供，**不提供任何担保**。

## 核心能力（截至 v0.6.10）

- **接回旧记忆（DeepSeek v3 ZIP 导入 & 深空重逢）**
  - 支持导入 DeepSeek 官方导出的 v3 ZIP 旧聊天记录；导入预览默认展开「近 7 天活跃」对话，将更早记录、疑似工具问答与无法导入项折叠收纳。
  - **一键智能分角色**：可自动聚合同一角色的多段历史对话、筛选有效片段、生成角色名、对你的称呼、自然人设与代表语气。
  - **进房深空回忆与「我们终于再会」重逢仪式**：新导入或唤醒的角色首次进入房间时，顶栏深空浮窗逐条呈现真实往事独白，随后进入脉冲星白场「我们终于再会」定格画面，点击「进入聊天」即可接着聊下去；系统返回手势始终可用，遇到网络波动或超时也可直接进入聊天。
- **单聊与群聊（「不吵」的一起聊）**
  - **一对一陪伴**：流式回复、停下、重新生成、复制、删除；TA 说话不带气泡，支持轻量加粗与斜体动作渲染。
  - **一起聊（2–4 个角色）**：默认每轮只由 1 个 TA 接话，不抢话、不刷屏；支持 `@` 点名（最多点两个，`@所有人` 也不会刷屏）。
  - **自动滚动与「回到最新」**：单聊与群聊统一对齐流式跟随体验，向上翻看历史时自动停住并出现「回到最新」按钮，一键回到最新消息。
  - **群聊安全预重连与重试**：开口前若遇瞬时网络抖动或限流可自动安全重连一次（零重复计费风险），失败时明确告知原因并支持原位点击重试。
- **「入戏 / 出戏」与创作模式**
  - 聊天页顶栏提供一键「入戏 / 出戏」切换（也可在设置中开启创作模式），支持更细腻、更有画面感的陪伴与故事表达；协议底线与危机兜底始终保留。
  - 填 DeepSeek 官方地址时，输入框上方提供「深度思考」与「智能搜索」开关，设置里可调「思考强度」（低 / 高 / 极高）。
  - 支持向 DeepSeek 发送文件；智能搜索与网页阅读可展示引用来源。文件会上传给 DeepSeek 处理，远端文件清理可能需要等待网络恢复。
- **语音输入、系统朗读与识图**
  - **语音输入**：按住说话、松手转文字，不自动发送，录音转写完即删。
  - **自动朗读**：1:1 聊天中可使用手机自带语音引擎朗读刚完成的回复，语速 4 档可调。
  - **识图**：1:1 聊天支持拍照或从相册选图（一次最多 3 张，本地缩放后发送），支持查看大图与「再用这张图问一次」。
- **双时态记忆与自主数据管理**
  - 每 8–12 轮自动整理记忆，提到往事时按原话或语义（「找旧事」）找回旧片段；「TA 记得的事」面板看得见、能改、能删，删了就会同步清理派生数据。
  - 支持导出 JSON 备份与从备份恢复（新增副本、不覆盖现有数据），支持随时清空全部本地数据。

## 构建与校验

需要 **JDK 17** + **Android SDK**（`compileSdk 36` / `targetSdk 36` / `minSdk 31` / `buildToolsVersion 36.0.0`）。

本仓库未提交 Gradle Wrapper（无 `gradlew`），构建时使用本地 Gradle 8.11.1：

```powershell
# 1. 指定本地 Android SDK 路径
"sdk.dir=C:\path\to\android-sdk" | Set-Content local.properties

# 2. 构建调试包
& '.\tools\gradle-8.11.1\bin\gradle.bat' --no-daemon --console=plain assembleDebug

# 3. 构建签名发布包（需配置 keystore.properties，无配置则产出 unsigned APK）
& '.\tools\gradle-8.11.1\bin\gradle.bat' --no-daemon --console=plain assembleRelease
```
